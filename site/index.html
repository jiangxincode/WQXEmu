何为文曲星？

文曲星是中国金远见公司生产的系列电子词典，自1990年代末起风靡全国。 它不仅是一台词典，更是无数80、90后的青春记忆——

在那个智能手机尚未普及的年代，文曲星承载了我们的课堂笔记、课间游戏、和对编程的最初探索。

核心特性

精确的硬件仿真，完整的功能实现

6502/W65C02 CPU

周期精确的指令执行，完整支持 BCD 模式和所有寻址模式

LCD 显示

160×80 像素，4 灰度级别，支持残影和格栅效果

键盘输入

完整的 QWERTY 键盘矩阵仿真，支持多机型键位布局

定时器系统

多个定时器源，中断生成，RTC 实时时钟

音频系统

SPDS104A DSP 仿真，支持音调生成和音频输出

RetroArch 核心

libretro 集成，支持 RetroArch 前端的所有功能

快速开始

几步即可运行文曲星模拟器

1

获取固件

从文曲星硬件 dump 固件文件，或从社区获取

2

下载 WQXEmu

从 GitHub Releases 下载对应平台的二进制文件

3

运行模拟器

wqxemu --model nc1020 \
  --rom obj_lu.bin \
  --nor nc1020.fls

固件要求

机型 必需固件 可选固件
NC1020ROM + NOR—
PC1000ROM + NOR—
CC800ROM + NOR—
NC2000NOR + NAND + NAND0—
NC3000NOR + NANDNAND0

从源码构建

需要 Rust 工具链

独立模式

cargo build --release
cargo run --release -- \
  --model nc1020 \
  --rom roms/nc1020/obj_lu.bin \
  --nor roms/nc1020/nc1020.fls

Libretro 核心

cargo build -p wqxemu-libretro --release

编译后的核心文件可加载到 RetroArch 中使用
